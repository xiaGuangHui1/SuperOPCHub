# SuperOPCHub · 超级个体枢纽

> **一个搜「人」的引擎。**
> 普通搜索引擎搜的是**网页**，它搜的是**人**。

---

## 它在解决什么问题

**甲方的难——说不清。**

「我想做个像淘宝但简单点的」——他其实不知道自己要什么、该找谁、市价多少。
人类中介的价值，就在于翻译这段模糊的表达。

**乙方的难——没人懂。**

一个人做公司（OPC = One-Person Company）的人，最缺的不是能力，是**被需要他们的人找到**。
他们散落在全网，没有统一入口。

> **看不懂，就看不见；看不见，就找不到。**
